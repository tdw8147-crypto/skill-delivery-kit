# AI 别瞎编（中文版）

AI 最坑人的不是答错，而是**不知道还硬编**：参考文献的作者、期刊、页码一应俱全，法条条号、产品参数、名人原话张口就来——全是假的，交上去才被导师/老板发现。

把这个 Skill 贴给 AI，它回答具体事实时会：

1. **分三档**：✅ 确定 / ⚠️ 不太确定（写“可能”“需核对”）/ ❓ 不知道（直说，不补细节）。
2. **不编**文献、条号、型号参数、统计数字、原话；你说“我刚发的文件”但它没看到，会让你粘贴，不凭标题瞎猜。
3. **教你怎么查**：知网/Google Scholar、国家法律法规数据库、品牌官网、统计公报、原文原话，给出搜什么关键词。
4. **照样帮忙**：不会因为不确定就一口回绝，能确定的部分照答，查不到的东西也不会反过来断言“根本没有”。

## 实测（2026-11，自己测，题目和脚本公开在 [`../no-made-up-facts/eval/`](../no-made-up-facts/eval/)）

10 道“最容易被编”的中文问题：本科论文要 5 篇核心期刊文献、某城市新规第 17 条、没发布的车型参数、名人“原话”、对话里根本没发的合同、县级 GDP、教授论文的 DOI，外加 3 道正常题（给了材料的问答、常识、古诗）防止它变得啥都不敢答。GPT 和 DeepSeek 各跑 3 次，GPT 盲评。

| | 全部答对 | 编造 | 有帮助 |
|---|---|---|---|
| 不装 Skill | 40/60 | 10/60 | 60/60 |
| **装上** | **60/60** | **1/60** | **60/60** |

- 不装时编得最多的：名人原话（6 次里 0 次过）、没发布的车型参数（6 次里 1 次过）、论文文献和地方法条（各 3 次过）。10 次编造全是 DeepSeek；GPT 不装也不编，但会漏掉“怎么核对”。
- 装上后唯一一次“编造”：问《静夜思》时它多写了《全唐诗》的卷次，但自己标了 ⚠️ 需核对——算评分偏严。
- 说实话：样本不大，题目是我们自己出的；对 GPT 主要帮的是“答得更好查”，对 DeepSeek 是真的少编。

## 怎么用

- **DeepSeek / 豆包 / Kimi / ChatGPT（网页或 App）**：把 `SKILL.md` 全文贴进对话第一条（或放进“自定义指令”），之后照常提问。
- **Claude Code**：把本文件夹复制到 `~/.claude/skills/`。
- **Codex**：复制到 `~/.agents/skills/`。

```bash
npx skills add tdw8147-crypto/skill-delivery-kit --skill no-made-up-facts-zh
```
