# 响应式表单输入核对（中文版）

表单显示正确但校验或联动状态不同步时，分层记录输入是否生效，不提交表单。

这是 [`reactive-form-input`](../reactive-form-input/) 的中文独立版，内容与该目录下的 `SKILL.zh.md` 相同，单独成文件夹是为了能用安装工具直接装。中文版和英文版装一个就够。

## 安装

```bash
npx skills add tdw8147-crypto/skill-delivery-kit --skill reactive-form-input-zh
```

或手动把本文件夹复制到 `~/.claude/skills/`（Claude Code）或 `~/.agents/skills/`（Codex）。聊天应用直接粘贴 `SKILL.md` 的内容。
