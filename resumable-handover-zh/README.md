# 换窗口交接纸条（中文版）

对话太长要开新窗口、上下文要被压缩时用。把它贴给 AI，再随口说一句“总结一下，我要开新对话”，AI 就会写出一张**交接纸条**：新窗口只看这张纸条，就能接着干——名字、数字、确认号原样保留，你否掉的方案不会再冒出来，还没定的事不会被它擅自决定，结果不明的操作不会被重做。

适合：DeepSeek 提示“达到对话长度上限”、ChatGPT/豆包/Kimi 聊久了忘事、Claude Code `/compact` 后丢规矩。

## 长对话实测：换两次窗口（2026-11-17，DeepSeek）

真实用户是这样用的：聊得很长、中途改口很多、换好几次窗口、只会说一句“总结一下”。所以我们按这个又测了一轮：

- 4 段我们自己项目里的真事改写成的长对话（每段约 2.3 万字），换**两次**窗口，每次只说“总结一下”；
- 第三个窗口只看最后那张纸条，回答 9～10 个真人会问的追问，共 370 道；GPT 对照完整原对话判对错；
- deepseek-v4.1-flash，每个场景装/不装各 10 次。

| | 不装 | 装这个技能 |
|---|---|---|
| 370 道追问答对 | 63% | **78%** |
| 技能写好之后才加的新场景（评论区规矩） | 51% | **87%** |

说实话：换两次窗口后，装不装都很难“全部答对”（装上 2/40 次全对，不装 0/40）；装上只是丢得少。最常丢的是“到底否掉的是旧的还是新的”和“试过但失败的结果”——所以新窗口第一件事，请你自己扫一眼纸条。[测法和脚本](../resumable-handover/eval-fish/README.md)

## 观众场景实测：写小说 / 考研计划 / 记账小程序（2026-11-17，DeepSeek）

上面用的是我们自己项目的聊天；这一轮换成普通用户自己会聊的事，**对话全部公开**。换两次窗口、每次只说“总结一下”，第三个窗口回答 9 道追问：答对 **71% → 80%**。例子：写小说时“灯塔钥匙在谁手上”4/9 → 10/10；考研时“推荐个付费网课”（用户说过只用免费资料）4/10 → 10/10。也有变差的：“帮我排下周计划”装了反而先反问、不直接排（2/10 → 0/10），想让它直接干就明说“别问，直接排”。[测法、每道题和对话原文](../resumable-handover/eval-viewer/README.md)

## 更早的实测：短对话、换一次窗口

6 个真实场景（写小说、改简历、家庭旅行、修 bug、定时发视频、批量改名），每个都藏着改口、作废、没定、结果不明的坑。新窗口只看交接，回答 6～7 个像真人一样的追问，盲评对照原对话打分。GPT + DeepSeek 各跑 2 次。

用户只说“总结一下”时：

| | 平均分 | 全部答对 |
|---|---|---|
| 不装 Skill | 0.95 | 16/24 |
| planning-with-files（热门竞品，只测技能正文和模板，没测它的 Claude Code 插件） | 0.95 | 18/24 |
| 我们上一版 | 0.94 | 18/24 |
| **这一版** | **0.98** | **21/24** |

说实话：样本不大；如果你本来就会写很讲究的交接提示词，装不装差别不大（0.96 对 0.95）。它帮的是不会写提示词的人——随口一句，效果不输精心写的提示词。

## 怎么用

- **DeepSeek / ChatGPT / 豆包 / Kimi（网页或 App）**：把 `SKILL.md` 全文贴进对话，再说“总结一下，我要开新对话”。把它写的纸条复制到新窗口第一条。
- **Claude Code**：把本文件夹复制到 `~/.claude/skills/`。
- **Codex**：复制到 `~/.agents/skills/`。

```bash
npx skills add tdw8147-crypto/skill-delivery-kit --skill resumable-handover-zh
```
