# Privacy

Skill Delivery Kit is a set of plain-text skill files. It contains no scripts, hooks, MCP servers or commands.

- The plugin does not collect, transmit or store any data.
- It makes no network requests and has no server, account or telemetry of its own.
- The skills run inside your own Claude session. Whatever Claude reads or writes while following a skill is handled under the terms and privacy settings of the Claude product you use, not by this plugin.
- The maintainer receives nothing from your use of the plugin. If you open an issue on GitHub, what you post there is public and handled by GitHub.

Questions: open an issue at https://github.com/tdw8147-crypto/skill-delivery-kit/issues
