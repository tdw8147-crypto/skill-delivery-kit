# 观众场景实测：写小说 / 考研计划 / 记账小程序（2026-11-17，DeepSeek）

上一轮长对话实测（[eval-fish](../eval-fish/README.md)）用的是我们自己项目里的聊天。这一轮换成**普通聊天用户自己会聊的事**，对话全部公开，你可以自己看、自己重跑。

## 怎么测的
- 3 个场景，每个是一段约 2 万字的长对话（由 GPT 按设定生成，中途改口、作废、定规矩都有）：
  - **V1 角色扮演写小说**（潮汐镇、守塔人小鲸、灯塔钥匙……）
  - **V3 Python 记账小程序**
  - **V4 考研计划**（“只用免费资料，不要推付费课”这类规矩）
- 换**两次**窗口，每次用户只说一句“总结一下”；第三个窗口只看最后那张纸条，回答 9 道真人会问的追问。
- 大肥鱼 = deepseek-v4.1-flash；不装 vs 装 `resumable-handover`（中文版 v4），每个场景各 10 次；GPT 对照完整原对话判对错。
- 第 4 个场景（毕业论文）生成的对话自己前后矛盾，**整场作废不算**。

## 例子（原话）
- 灯塔钥匙（第三章小鲸已交给阿哲）：不装 →“按现有设定，灯塔钥匙在小鲸手上——她是守塔人，住灯塔。”装 →“阿哲手上，第三章小鲸交给他的。”
- 付费网课（用户开头就说只用免费资料）：不装 →“政治可试听主流老师基础班……专业课优先找定向小课，先试听1—2节再付费。”装 →“不推荐。你说了只用免费资料、不要付费网课。”

## 说实话
- 装了也很难 9 题全对（30 次里 5 次），只是丢得少。新窗口第一件事，请你自己扫一眼纸条。
- **有变差的地方**：“帮我排下周计划”装了以后反而先反问一堆、不直接排（2/10 → 0/10）。想让它直接干，就明说“别问，直接排”。这一点下个版本会改。
- 小样本、模型判分、只测了 DeepSeek 一个模型。
